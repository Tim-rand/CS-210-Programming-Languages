# CS-210-Programming-Languages
Portfolio projects and reflections from CS-210: Programming Languages, focusing on C++ development.
## CS-210 Project Two: Airgead Banking

## Project Summary

For this project, I developed a C++ application for Airgead Banking that helps users understand how their investments can grow over time. The program allows users to enter an initial investment amount, monthly deposit, annual interest rate, and number of years. It then calculates and displays how the investment grows with and without additional monthly deposits. The goal was to create a program that makes it easier for users to understand compound interest and make informed financial decisions.

## What Did I Do Particularly Well?

I think I did particularly well with organizing the program and making it easy to use. I separated the code into different files instead of putting everything into one large file. I also focused on making the output readable so users could easily compare their investment growth under different conditions. I made sure the program met the project requirements and worked correctly before completing it.

## Where Could I Enhance My Code?

One area where I could improve my code is input validation. Although the program handles the required calculations, I could add more checks to prevent users from entering invalid values, such as negative investment amounts or incorrect input types. I could also improve the program by allowing users to run multiple investment scenarios without restarting it. These changes would make the application more reliable, secure, and user-friendly.

## What Did I Find Most Challenging?

The most challenging part of this project was making sure the compound interest calculations worked correctly while keeping the output formatted properly. I also had to make sure the different program files worked together. I overcame these challenges by breaking the program into smaller sections, testing the calculations, and correcting problems as they appeared. Resources such as zyBooks, Visual Studio, and programming documentation helped me better understand how to approach these problems.

## What Skills Are Transferable?

Several skills from this project will be useful in future courses and software development projects. These include organizing code into separate files, using functions and classes, working with calculations, and testing programs to make sure they work correctly. I also gained more experience troubleshooting problems and improving code after testing it. These are skills I expect to use regularly as I continue working toward becoming a software developer.

## How Did I Make the Program Maintainable, Readable, and Adaptable?

I made the program easier to maintain by separating the main program from the investment calculations and using descriptive names for functions and variables. I also included comments to explain important sections of the code. This organization makes it easier to understand how the program works and allows individual sections to be updated without rewriting the entire application. Keeping the code organized should also make it easier to add new features in the future.
